部門技術棧與「達哥」企業生成式 AI 賦能

1. 入職前自主技術強化 (C# & Database)

面試階段掌握部門核心技術為 C# 應用程式開發與 SQL 資料庫管理後，於正式報到前完成語法與資料庫查詢自主演練，無縫銜接專案實作。

2. 一對一資深導師制度 (Mentor Program)

入職後由資深正職工程師一對一指導，快速熟悉半導體測試資料結構 (STDF/XML)、測試區 (QAS) 與正式區 (PROD) 佈署規範，大幅縮短適應期。

3. 內網資安環境下的「達哥」AI 協作除錯

廠區採高規格內網資安隔離，同時引進整合 GPT 與 Gemini 的企業級生成式 AI 平台「達哥」。遇到基礎語法或邏輯問題時，先透過 AI 進行第一線檢索與程式碼雛形產出，再進行嚴謹人工審核，顯著降低團隊溝通成本。

DATA COLLECTION & UTR VERIFICATION

DC 客戶資料下載/備份自動化與 UTR 測試報告

依據客戶需求表單進行資料自動下載或備份設定。從資料庫查詢歷史設定、測試 FTP 路徑連通性，於 Visual Studio 撰寫或擴充 XML 設定檔（搭配 AI 輔助生成後進行人工嚴格校驗），最後透過 ClickOnce 監控執行狀態並撰寫完整 UTR 報告。

過濾規則設定：精準排除特定前綴（如 CORR）或副檔名（如 .txt），建立專屬 OPTION 參數。
三階段傳輸管線： FTPSCAN（進 WORKSPACE 備份）→ FILEUPDATE（轉移至 HOTFILES）→ DC_FILTER（派送至客戶指定目錄）。
UTR 品質保證文件：完整收錄 SQL 查詢/新增語法、測試前後截圖與檔案路徑比對佐證。
// DC_OPTION_CONFIG_SAMPLE.xml (去識別化範例) STATUS: SUCCESS 
<DC_Config Plant="CL_H2" Customer="CLIENT_DEMO">
  <TransferMode>DOWNLOAD_AND_BACKUP</TransferMode>
  <FilterRules>
    <ExcludePrefix>CORR_</ExcludePrefix>
    <ExcludeExtension>.txt</ExcludeExtension>
  </FilterRules>
  <Pipeline>
    <Step1>FTPSCAN -> /WORKSPACE/STDF/</Step1>
    <Step2>FILEUPDATE -> /HOTFILES/</Step2>
    <Step3>DC_FILTER -> /TARGET_DEST/</Step3>
  </Pipeline>
</DC_Config>
實習洞察：AI 生成 XML 程式碼雖快，但偶爾會出現標籤閉合或正規表示法偏差，透過「AI 初稿 + 人工逐行審核 + QAS 測試驗證」可將上線錯誤率降至零。

WAFER TALLY EXECUTION PIPELINE

Tally 測試數據解析與良率驗證標準三步驟

STEP 01 · DB CONFIGURATION

資料庫解析規則確認

前往 Database 設定表核對 Tester 與 Customer 對應的解析規則、Pattern 比對邏輯以及 Bin 分群設定是否完整建置。

STEP 02 · TRIGGER EVENT

執行 InsertEventAndTrigger

傳入 Lot、Wafer 與 Insertion 關鍵參數觸發事件，驅動後端系統自動執行 Tally 晶圓數據解析引擎。

STEP 03 · BIN VERIFICATION

HW/SW BIN 寫入與數量核對

待系統回傳 Success 後，查詢資料庫確認 HW BIN 與 SW BIN 是否正確寫入，並驗證 Pass/Fail 數量與客戶需求單完全一致。

FORM 2DID SYSTEM ENHANCEMENT

Form 2DID 頁面四大核心功能優化

針對既有的 Form 2DID 作業系統進行全面性功能擴充，涵蓋彈性上傳路徑、跨動作紀錄整合查詢、FTP 自動撈檔與高安全性防呆刪除機制。

1. 上傳路徑彈性化

在原本 Upload 頁面多加了目的地的下拉選單，可以自己挑要傳去哪，並如有新的需求還可以擴充增加更多路徑。

2. 查詢更方便

Query 頁面可以用使用者、檔名或時間區間來篩選，而且把 Upload 跟 Delete 的紀錄整合在一起看，找紀錄快很多。

3. 支援下載檔案

新做的 Download 功能只要輸入 Lot 號，系統就會自己用 FTP 把對應的 Lot 檔案撈下來到本機。

4. 安全刪除與備份機制

新增 Delete 功能刪掉指定的 REELID 資料：先檢查資料是否存在、限制僅能輸入英數字元防誤刪，刪除後自動備份 REELID 與 USERID 至 Database。

Form 2DID · Delete 防呆與 DB 備份模擬 SQL AUDIT ON
請輸入 REELID 測試字元防呆檢核（禁止特殊符號）與刪除後自動寫入 Database 備份紀錄。
GIT HOOK DEVOPS AUTOMATION

eMap+ Scenario XML 的 .ppk 金鑰自動檢查

過去開發團隊在發版合併（Merge）Scenario XML 設定檔時，若有人忘記設定 SFTP 的 .ppk 金鑰，會導致上線後的檔案傳輸直接異常中斷。

① Git Hook 背景觸發：串接 XmlCompareHook.exe，在執行 Merge 時自動掃描異動的 XML 內容。
② 缺失自動阻擋推送：只要抓到程式碼中未設定 .ppk 金鑰路徑，立即阻擋推送並提示錯誤，補齊後才予以放行。
